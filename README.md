# 🌟 Нур-Базар — Кургатылган жемиштер онлайн дүкөнү (2026)

**Нур-Базар** — бул Баткендин эң мыкты табигый кургатылган жемиштерин жана жаңгактарын саткан заманбап онлайн платформа. Долбоор колдонуучуларга ыңгайлуулук түзүү үчүн акыркы технологияларды (AI, React) камтыйт.

---

## ✨ Өзгөчөлүктөрү (Особенности)

- 🌙 **Рамазан 2026 режими**: 2026-жылдын 19-февралынан 20-мартына чейин автоматтык түрдө Рамазан маанайына өтөт, 10% арзандатууларды эсептейт жана майрамдык баннерди көрсөтөт.
- 🤖 **AI Жардамчы (Gemini API)**: Кардарларга жемиштердин пайдасы тууралуу маалымат берип, тандоого жардам берген акылдуу консультант.
- 📱 **WhatsApp Интеграция**: Заказдарды бир чыкылдатуу менен түз сатуучунун WhatsApp номерине жөнөтүү.
- 🛠 **Админ Панель**: Товарларды кошуу, өчүрүү жана бааларын өзгөртүү мүмкүнчүлүгү.
- 🌍 **Эки тилдүүлүк**: Кыргыз жана орус тилдерин колдоо.
- 🎨 **Заманбап Дизайн**: Анимацияланган Hero бөлүмү жана адаптивдүү интерфейс.

## 🛠 Кантип иштетүү керек? (Как запустить?)

1. Долбоорду көчүрүп алыңыз (Clone the repo):
   ```bash
   git clone https://github.com/колдонуучунун-аты/nur-bazar.git
   ```

2. Көз карандылыктарды орнотуңуз (Install dependencies):
   ```bash
   npm install
   ```

3. API ачкычты тууралаңыз:
   Долбоордун иштеши үчүн `.env` файлына `API_KEY` (Gemini API) кошууңуз керек.

4. Долбоорду баштаңыз (Start development):
   ```bash
   npm start
   ```
